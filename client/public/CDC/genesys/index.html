09·A

Call Center AI Agent on Genesys Cloud

One AI agent for every customer contact, before, during and after the call. It is grounded in the Item ontology and plugs natively into Genesys Cloud.

01

Understands

Captures intent, serial and context in the IVA or virtual agent; pre-fetches entitlement and case history.

02

Guides

Pushes the next-best step from the approved SOP and the right knowledge, and validates parts and serials instantly.

03

Acts

One-click execution: case notes, work orders and follow-ups written back to Dynamics 365.

04

Learns

Learns from outcome data and proposes better SOPs, with experts approving every change.

Platform

Built for Genesys Cloud, ready for the Engage-to-Cloud migration.

Genesys has set 31 December 2028 as the end of Genesys Engage on-premises and focuses future investment on Genesys Cloud. The AI agent is designed for Genesys Cloud from day one, so the customer's platform migration and its AI roadmap move forward together.

09·M

Roadmap Aligned with the Genesys Cloud Migration

Start on today’s data and scale on Genesys Cloud. Timing follows the customer’s migration plan.

Phase 1 · Start now

On current data

  • Customer service ontology: case, asset, part, entitlement, SOP
  • Top contact reasons and baselines
  • Expert-approved SOP library v1
  • AI agent in Dynamics 365: notes, entitlement, part validation, safety rules
Phase 2 · With the migration

Unlocked on Genesys Cloud

  • Real-time assist via AudioHook + Interaction Widget
  • SOPs published to Copilot, scripts and checklists
  • Speech & text analytics topics, AI-scored QA
  • Virtual agent intent capture handed to agents
Phase 3 · Optimize

At scale

  • Outcome-driven SOP loop across SG and MY
  • Proactive status updates (O2 / O12)
  • Predictive routing and journey analytics
  • Knowledge lifecycle and onboarding paths
How this sits against the four-week case study. They measure different things. The four weeks in section 09 is time-to-first-value on a contact-centre platform that already exists: API ontology, business knowledge, assistant and ticket sync. The three phases here are the full programme on a platform that is still migrating — phase 1 runs on today's data and does not wait for the migration, phase 2 unlocks only once Genesys Cloud is live, and phase 3 is continuous. Read the four weeks as what the first working assistant costs, and these phases as what the complete capability costs.
Indicative timing: Phase 1 in roughly the first three months; Phase 2 aligned with the Genesys Cloud cut-over; Phase 3 ongoing.
